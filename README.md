# 環境知識每日挑戰

開啟 `index.html` 即可使用，不需要伺服器或額外套件。

## 功能

- 每天依臺灣日期固定抽取 40 題，同一天重新開啟會得到相同題組。
- 開啟時自動讀取已發布的 Google 試算表 CSV 題庫。
- 雲端題庫讀取失敗時，會自動使用網站內建題庫。
- 送出前會檢查是否全部作答。
- 送出後顯示分數、答對率，以及每一題錯題的你的答案、正確答案與詳解。
- 支援從 Google 試算表下載的 `.csv` 或 `.json` 匯入題庫。
- 手機、平板與桌機皆可使用，版面會自動縮放。

## Google 題庫欄位

第一列請使用以下欄位名稱：

```text
category,question,optionA,optionB,optionC,optionD,answer,explanation
```

`answer` 可填 `A`、`B`、`C`、`D`，或填 0、1、2、3。題目與詳解內含逗號時，請依 CSV 規則使用雙引號包住欄位。

目前網站已連結至已發布的 Google 試算表 CSV；更新試算表後，重新整理網站即可取得新題庫。
