# 環境知識每日挑戰

開啟 `index.html` 即可使用，不需要伺服器或額外套件。

## 功能

- 依臺灣日期每天固定抽取 40 題，同一天重新開啟會得到相同題組。
- 送出前會檢查是否全部作答。
- 送出後顯示分數、答對率，以及每一題錯題的你的答案、正確答案與詳解。
- 支援從 Google 試算表下載的 `.csv` 或 `.json` 匯入題庫；匯入題庫至少需要 40 題。
- 手機、平板與桌機皆可使用，版面會自動縮放。

## CSV 欄位

第一列請使用以下欄位名稱：

```text
category,question,optionA,optionB,optionC,optionD,answer,explanation
```

`answer` 可填 `A`、`B`、`C`、`D`，或填 0、1、2、3。若題目或詳解內含逗號，請依 CSV 規則使用雙引號包住欄位。

## JSON 格式

```json
[
  {
    "category": "環境倫理",
    "question": "題目文字",
    "options": ["選項 A", "選項 B", "選項 C", "選項 D"],
    "answer": 0,
    "explanation": "詳解文字"
  }
]
```

目前內建 48 題，內容整理自專案中的六大主題教材：循環經濟、無形文化資產、綠生活、綠色能源、臺灣 2050 淨零與環境倫理。
